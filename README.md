# MediPlan – Intelligent Hospital Floor Planning System

## Problem Statement
Hospital planning requires complex decisions involving room allocation, department connectivity, patient movement, accessibility, and resource optimization. Traditional manual planning methods are time-consuming and require multiple iterations. There is a need for an AI-powered platform that simplifies hospital floor planning and generates optimized layouts using advanced artificial intelligence techniques.

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js 
- **Database:** MongoDB 
- **AI Models:** CNN, Graphormer, GAN  
- **Visualization:** Recharts, Framer Motion  
- **Deployment:** Vercel  

## Features

### Hospital Layout Generation
- Generate optimized hospital floor plans based on healthcare infrastructure requirements  
- Automatically organize departments, rooms, and functional spaces  
- Improve space utilization and planning efficiency  

### AI Floor Plan Visualization
- Create realistic AI-generated hospital layouts  
- Visualize optimized floor plans through interactive interfaces  
- Provide intelligent layout recommendations using AI models  

### Planning Analytics
- Analyze hospital space utilization and resource distribution  
- Monitor department allocation and planning performance  
- Provide data-driven insights for better infrastructure decisions  

### Layout Export Services
- Export generated hospital floor plans in multiple formats  
- Save AI-generated layouts for future planning and analysis  
- Support easy sharing of optimized designs  

## AI Architecture

### CNN-Based Analysis
- Predict room sizes, locations, and spatial requirements  
- Analyze existing hospital planning patterns  

### Graphormer Optimization
- Understand relationships between departments and rooms  
- Optimize connectivity, accessibility, and patient flow  

### GAN Layout Generation
- Generate realistic and optimized hospital floor plans  
- Improve design quality using AI-based layout generation
